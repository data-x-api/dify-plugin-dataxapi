# DataXAPI 社媒与市场数据（Dify 插件）

在 Dify 的工作流、Chatflow 和 Agent 里取抖音、小红书、微信公众号、视频号、微博、B站、知乎、快手的公开数据，也能取巨量算数（抖音指数）、蒲公英、星图，以及 TikTok、YouTube、X、Reddit。一把 [DataXAPI](https://dataxapi.com/zh/?ref=dify) Key，36 个现成工具，另外用“找接口”和“调用任意接口”能用到全部 237 个接口。

- **不用登录你自己的平台账号**，不用 Cookie、不用扫码。
- **按次付费，出错不收费。**每个工具写明了价格，每次结果里的 `billing.amount` 写明这次扣了多少（美元）。
- **免费试用，最多 333 次，不用绑卡。**最低充 $10，余额不过期；支持支付宝、微信支付和银行卡。

源码：<https://github.com/data-x-api/dify-plugin-dataxapi> · 联系：support@dataxapi.com

## 拿来做什么

**每天盯竞品公众号，出一份简报。**“公众号实时查找”按名字找到账号的原始编号（`gh_` 开头）→“微信公众号文章列表”取最新文章 → 迭代节点对每篇调“微信公众号文章互动数据”拿阅读、点赞、分享 → LLM 节点写成简报：谁发了什么、哪篇阅读最高。每天定时跑。

**小红书品牌口碑日报。**“小红书笔记搜索”搜你的品牌名、排序选 latest → 对点赞最多的几篇调“小红书笔记评论”→ LLM 节点按好评、差评、问题归类，附原笔记链接。

**选题前先看热度。**“抖音巨量算数关键词热度趋势”一次查 1 到 5 个词的逐日搜索指数，带上期和去年同期 →“抖音巨量算数关联词”看大家还在搜什么 →“小红书蒲公英关键词逐日搜索指数”看同一个词在小红书的热度 → LLM 判断哪个词在涨。

**让 Agent 自己找数据。**给 Agent 打开“找接口”和“调用任意接口”：它先用一句话（比如“视频号评论”“B站 UP 主粉丝数”）找到接口和参数（免费），再去调用。36 个现成工具没覆盖的，这样也能用。

## 安装和配置

1. 在 DataXAPI 控制台创建 Key：<https://dataxapi.com/console/keys/?ref=dify>。
2. 在 Dify 插件市场搜 DataXAPI 安装，打开工具设置，把 Key（`dx_` 开头）填进凭证。
3. Dify 用免费的 `GET /v1/account` 校验 Key，不扣钱。

## 返回什么

每个工具返回 JSON：`data`（`items` 列表或单个对象）、`page.next_cursor`、`warnings`、`billing`（`amount`、`balance_after`）、`request_id`。作品、评论、账号在各个平台用同一套字段，一个工作流换个平台不用改后面的节点。字段说明见 [dataxapi.com/zh/docs](https://dataxapi.com/zh/docs/?ref=dify)。

出错时返回一段文字，写明错误码、扣没扣钱、能不能重试。

## 网络连接

插件只向 `https://api.dataxapi.com` 发 HTTPS 请求，带 `Authorization: Bearer <key>` 和 `X-Source: dify`。不需要别的网络访问。

## 本地开发和测试

需要 Python 3.12 和 [uv](https://docs.astral.sh/uv/)。

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -r requirements-dev.txt
.venv/bin/python -m pytest
```

测试把所有 HTTP 请求都 mock 掉，不会调用收费接口。工具由 `scripts/generate_tools.py` 从 DataXAPI 的实时目录生成；目录或价格变了，重新运行它。
